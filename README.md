# Sprint-7-vehicles-project 🚗

## Dashboard de vehículos en venta

Esta aplicación web permite explorar un conjunto de datos de anuncios de coches en Estados Unidos mediante visualizaciones interactivas.

## Funcionalidades

- Visualización de la distribución del odómetro
- Relación entre precio y kilometraje mediante gráfico de dispersión
- Interacción mediante casillas de verificación

## Tecnologías

- Python
- Pandas
- Plotly
- Streamlit

## Cómo ejecutar

pip install -r requirements.txt  
streamlit run app.py
